Setup walkthrough — Google Apps Script Web App
  1. Open your Outreach Google Sheet.
  2. Top menu: Extensions → Apps Script.
  3. Delete the default function myFunction() { ... } stub. Open the file apps-script/Code.gs from this extension's folder, copy everything, and paste it into the Apps Script editor.
  4. At the top, replace SECRET_TOKEN = 'REPLACE_ME_WITH_A_RANDOM_STRING' with a long random string. Copy that same string into the "Shared Secret Token" field above.
  5. Click the floppy-disk Save icon.
  6. Top right: Deploy → New deployment.
  7. Click the gear ⚙ icon → choose Web app.
  8. Settings:
    • Description: Kengo InMail proxy
    • Execute as: Me (your-email@gmail.com)
    • Who has access: Anyone ← required (the SECRET_TOKEN gates real access)
  9. Click Deploy. Authorize when prompted (it's your own script, so trust it).
  10. Copy the Web app URL. Looks like https://script.google.com/macros/s/AKfy.../exec. Paste it above.
  11. Click Test connection here. You should see ✓ Connected.
  12. If you ever edit Code.gs: Apps Script → Deploy → Manage deployments → pencil → Version: New version → Deploy. URL stays the same.
